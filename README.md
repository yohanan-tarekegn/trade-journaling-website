# Trade Journal Web App

Situation:
I love trying new things , so i got into daytrading
As a day trader, I needed a reliable way to track my trades and analyze my performance. Subscription services like TradeZella were too expensive for me.

Task:
I wanted an affordable, personalized solution to log trades, monitor progress, and gain insights into my trading strategies.

Action:
I leveraged my frontend development skills to build a web-based trading journal. The app allows traders to input trade data, track performance metrics, visualize progress, and reflect on trading strategies—all in a clean and intuitive interface.

Result:
I now have a fully functional, cost-effective trading journal that helps me monitor my trades, improve decision-making, and optimize performance. It also serves as a template for other traders seeking an affordable, self-hosted alternative to commercial solutions.

Features:

Log trades with essential details (entry, exit, size, instrument)

Track performance metrics over time

User-friendly frontend interface

Free and customizable alternative to paid trade journals
